김영한의 실전 자바 - 중급 1편

11. 다음으로

인프런 김영한 강사님의 "김영한의 실전 자바 - 중급 1편" 강의를 듣고 정리한 학습 노트입니다. 강의 PDF를 그대로 옮긴 것이 아니라, 강의에서 설명한 흐름과 예시를 제 나름대로 재구성했습니다.

이 강의를 관통하는 태도 — "왜?"

  • 이 코스가 유독 분량이 많았던 이유는 매 주제마다 "그냥 문법이 이렇다"가 아니라 "왜 이렇게 설계됐는가"를 계속 캐물었기 때문이다 — Object가 왜 최상위인지, 왜 불변으로 설계된 클래스가 많은지, 왜 예외 처리 메커니즘이 필요한지.
  • 단순히 API 사용법을 아는 것과, 그 이유를 이해하는 것은 완전히 다른 수준의 이해로 이어진다는 게 강의 전체의 일관된 메시지.

9개 섹션 한 줄 회고

  • Object와 다형성 — 모든 객체의 최상위 부모, equals/toString, 동일성과 동등성의 구분이 이후 모든 내용의 토대가 됐다.
  • 불변 객체 — 공유 참조와 사이드 이펙트라는 문제를 이해해야, String이나 래퍼 타입이 왜 불변으로 설계됐는지가 납득된다.
  • String과 최적화 — 불변성의 실전 사례. StringBuilder를 쓰는 이유, 문자열 최적화는 면접에서도 자주 나오는 단골 주제.
  • 래퍼, Class 클래스 — 기본형의 한계를 메우는 래퍼 타입, 오토 박싱, 그리고 Class·리플렉션을 살짝 맛봤다.
  • 열거형(Enum) — 문자열의 타입 안전성 문제 → 타입 안전 열거형 패턴 → 언어가 지원하는 enum으로 이어지는 발전 과정이 핵심.
  • 날짜와 시간 — 상황(국내 서비스 vs 국제화 vs 절대시간)에 맞는 클래스를 고르는 감각이 실무에서 중요하다.
  • 중첩·내부 클래스 — 지역 변수 캡처, 익명 클래스까지가 사실은 람다로 넘어가기 위한 발판이었다.
  • 예외 처리(이론+실습) — "왜 필요한가"부터 시작해서 체크/언체크, finally, try-with-resources, 실무에서의 공통 처리까지 — 실무에서도 제대로 이해하고 쓰는 사람이 생각보다 많지 않다는 지적.

왜 자바 기본기인가

  • 백엔드 개발자에게 스프링 같은 프레임워크는 사실상 필수지만, 스프링도 결국 자바로 만들어진 코드다.
  • 자바 기본기가 탄탄하면 스프링이나 다른 오픈소스를 배우는 속도와 이해도가 완전히 달라진다 — 이 강의가 프레임워크보다 언어 기본기를 먼저 다루는 이유.

앞으로의 로드맵

  • 실전 자바 - 중급 2편: 제네릭과 컬렉션 프레임워크. 자료구조·알고리즘 기본기를 실무 관점에서 직접 구현하고 성능까지 측정해보는 실습 위주로 구성될 예정.
  • 실전 자바 - 고급편: 람다, 스트림, IO, 네트워크, 멀티스레드 등 심화 주제를 1편·2편으로 나누어 다룰 예정.
  • 백엔드 개발자 학습 순서 제안: 자바 기본기 → 데이터베이스 → 스프링.

정리

  • 이 코스의 진짜 목표는 API 암기가 아니라 "왜 이렇게 설계됐는가"를 스스로 물을 수 있게 되는 것이었다.
  • 불변 객체, 예외 처리, 다형성처럼 이 코스에서 다룬 개념들은 스프링을 포함한 대부분의 자바 생태계 코드를 읽을 때 계속 다시 마주치게 된다.
  • 다음 단계는 제네릭·컬렉션(중급 2편)과 람다·스트림·동시성(고급편) — 지금 다진 기본기가 그 내용을 이해하는 토대가 된다.
