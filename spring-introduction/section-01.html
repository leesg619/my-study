스프링 입문

1. 스프링 웹 개발 기초

기본 FLOW

웹 브라우저가 /hello url을 호출하면, 내장 톰캣 서버에서 자동으로 @GetMapping("hello")가 있는 컨트롤러를 찾는다. 리턴 값을 반환할 때 상황에 맞는 Handler / Resolver가 적절하게 처리한다.

스프링 정적 컨텐츠 동작 FLOW (static)

웹 브라우저가 /hello-static.html url을 호출하면, 내장 톰캣 서버가 요청을 받고 스프링 컨테이너에 넘겨준다. 스프링 컨테이너는 컨트롤러에서 먼저 찾고(우선순위를 가짐), 컨트롤러에 없다면 resources/static/hello-static.html을 찾아서 있다면 넘겨준다.

MVC 와 Template Engine 동작

웹 브라우저가 /hello-mvc?name=spring! url을 호출하면, 내장 톰캣 서버가 요청을 받고 스프링 컨테이너에 넘겨준다. 스프링 컨테이너에서 매핑된 컨트롤러를 찾고, Model에 name:spring!을 셋팅한 후 return "hello-template";하면 viewResolver가 동작하면서 템플릿 엔진을 연결시켜준다. 템플릿 엔진이 변환한 결과를 웹 브라우저에 넘겨주며 종료한다. 

@GetMapping("hello-mvc")
public String helloMvc(@RequestParam("name") String name, Model model) {
    model.addAttribute("name", name);
    return "hello-template";
}
